# Granted Hours publication privacy contract

Public calendar copy should retain useful evidence of human–AI collaboration without exposing the private circumstances behind it.

The fixed handling order is:

1. Rewrite the private passage as a bounded, readable account of the work or method.
2. Mask any remaining identifying entity with `████`.
3. Remove the whole item only when even an abstract description would disclose a private fact.

The public layer must not serialize intimate family narratives, relationship or caregiving details, physical or emotional states, medications or conditions, unpublished commercial briefs, media identities or collaboration context, account information, credentials, named deployment or data-terminal status, private holdings, or technical identifiers.

Safe public copy may still state the collaboration method and outcome: balancing long-term creative work with daily responsibilities, arranging personal recovery, structuring copy and release cadence, or checking external-service permissions and data-path availability.

Every import and build must run the semantic sanitizer, deterministic tests, and public safety scan. A failed gate blocks commit, push, and deployment; its log reports categories and counts only, never the matched source text.
