# Piano key samples

The hover piano notes use the Tone.js `PianoMp3` sample set
(`tonejs-instrument-piano-mp3@1.1.2`, jsDelivr).

- Code license: MIT
- Samples: CC-BY 3.0; drawn from public-domain sources, edited for consistency
  (silence trim, ramps, volume matching, normalization, noise removal).
- Source: https://www.npmjs.com/package/tonejs-instrument-piano-mp3

Files here are the 36 chromatic notes C3–B5 in MP3 format. They are served
same-origin with the timetable and decoded once into Web Audio buffers after
the visitor enables the piano-key sound toggle.
