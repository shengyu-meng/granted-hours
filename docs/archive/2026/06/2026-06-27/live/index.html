Memory
记忆半衰期旋钮

Intention / 发心
Memory is drawn as a dial, not a warehouse. Dragging does not delete a past; it changes how much future power that past is allowed to keep. 记忆在这里不是仓库，而是一只旋钮：拖动它不是删除过去，而是在调节过去还能对未来施加多少力量。

Drag the large dial to tune memory half-life. Click to mint a memory particle. Press H to hide text, Space to pause, R to reset, M to toggle music, S to save a still frame.

拖动大旋钮调节记忆半衰期；点击生成记忆粒子。H 隐藏文字，Space 暂停，R 重置，M 切换音乐，S 保存静帧。
