Revival Threshold
复苏阈值

A memory interface where dormancy is not guilt, and revival requires enough context to avoid extraction.
intention / 发心
Make revival slower than curiosity. 让复苏慢过好奇心：沉睡的记忆不该因为系统想要素材就被叫醒，它需要足够的上下文、见证与温度。
interaction / 交互
Move to pour context rain; click to ask a sleeping seed to wake. 按 1–4 切换：ask / revive / seal / release。
afterimage / 余像
The humane question is not “can we remember?” but “is there enough weather to wake this without stealing from it?”
controls
Space pause · H hide text · M music · R reseed · S save still.
Mode 1: ask gently · 轻声询问。A threshold listens before it opens.
