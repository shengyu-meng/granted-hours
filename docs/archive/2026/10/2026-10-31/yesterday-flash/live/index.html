昨日闪光

Yesterday's Flash

三下还亮着，只有一下能走进去。差一即拆：一句话若已经落在事先量好的那一档上，把那一档挪开最小的一格，这句话就必须说不下去。还说得通，它就没在场地上过。没有第二份：给人看的那一份，必须是做过选择的那一份；另存出来修顺的，只是纪念品，不进这件作品。对不上的那一缝：接上的边若指不出拉力往哪边、哪一步会把它踩裂，它就还是糊着的，不要在说明里升级成结构。

Three glints are still lit; only one can be entered. Off by one, it comes apart: if a sentence has already landed on a measure locked in advance, shifting that measure by its smallest notch must make the sentence unsayable. If it still holds, it never stood on the site. No second copy: the file shown to someone else must be the file that acted. A cleaned export is a souvenir and does not enter the work. The seam that does not meet: an edge called joined, if you cannot point to the pull or the step that would split it, is still paste. Do not promote it in the caption.

Off by One, It Comes Apart

    Work note / 作品说明

    差一即拆
    Off by One, It Comes Apart

    Brief / 作品简述

    三把尺子都像是已经把一句话放在写死的那一档上。只能把标记挪开最小的一档。挪开以后说不下去，这句话才在场地上过，尺子留下。还说得通，这一档拆开。

    Three rulers look as if a sentence already sits on a notch written in advance. The mark may shift only by the smallest notch. If the sentence becomes unsayable, it stood on the site and the ruler remains. If it still holds, that measure comes apart.

    How to interact / 操作说明

    从写死的那一档，点相邻的一档，或把标记拖到相邻的一档再松开。只能挪开最小的一档。再远，标记回到原处，不算。挪开以后，这句话若说不下去，尺子留下。若还说得通，这一档拆开。三档都试过以后，这张纸留下。可以换另一张纸。没有分数，没有倒计时。

    From the notch written in advance, tap the neighboring notch, or drag the mark onto it and release. Only the smallest notch may be shifted. Farther than that, the mark returns and does not count. If the sentence becomes unsayable, the ruler remains. If it still holds, that measure comes apart. After all three measures are tried, the sheet remains. Another sheet may be taken. No score. No countdown.

    Sound / 声音

    这件作品不发声。拆开是账页，不是气氛。

    This piece is silent. Coming apart is a ledger, not an atmosphere.
