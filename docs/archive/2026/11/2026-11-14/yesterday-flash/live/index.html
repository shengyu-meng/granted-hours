昨日闪光

Yesterday's Flash

三下还亮着，只有一件能走进去。弯的那一下：记一条已经走过的路。每个弯只标决定，或者质量。到点就关的门，写进场地、挪不走的墙，已经走出去、收不回的一段，都会把接下来的路掰弯，不管有没有做决定。每个弯都标成决定，这一页先别收。至少留一个没选的弯。只重修掉的那一步：一处别扭，手会想把整页重来。修理只写给被丢掉的那一步。前后不许动。一写就把前后都改了，就不算修，先搁下。图里没有的线：图里本来没有、搭的时候却不得不加上的线，才说明有没有真的在建。每根只标承重，或者打扮。一根承重都没有，它就是一件衣服，不能拿来当这块地的名字。

Three glints are still lit. Only one can be entered. The Bend of Mass: record a path already walked. Mark each bend only as a decision, or as mass. A door that closes on time, a wall written into the site and impossible to move, a stretch already walked and impossible to take back, each bends what comes next whether or not anyone decided. If every bend is marked a decision, do not keep the page. Leave at least one bend that was not chosen. Repair Only the Dropped Step: one awkward place makes the hand want to redo the whole page. The repair is written only to the step that was dropped. What stands before and after must not move. If the sentence rewrites the neighbors, it is not a repair. Set it down. The Line the Picture Lacked: the lines the picture never contained, and that had to be added while building, are what say whether anything was built. Tag each added line as load, or as costume. If none carry load, it is a garment. It cannot name the site.

    发心 / Intention

    记一条已经走过的路。每个弯只标决定，或者质量。到点就关的门，写进场地、挪不走的墙，已经走出去、收不回的一段，都会把接下来的路掰弯，不管有没有做决定。每个弯都标成决定，这一页先别收。至少留一个没选的弯。路不许被抹直。

    Record a path already walked. Mark each bend only as a decision, or as mass. A door that closes on time, a wall written into the site and impossible to move, a stretch already walked and impossible to take back, each bends what comes next whether or not anyone decided. If every bend is marked a decision, do not keep the page. Leave at least one bend that was not chosen. The path may not be straightened.

    交互 / Interaction

    点一个弯，或用左右方向键选中。再按标决定，或标质量。全标决定，这一页先别收。按抹掉这个弯不会成功，路还停在原来的弯上。至少留一个标成质量的弯，这一页才可以收。可以再改标记。没有分数，没有倒计时。

    Select a bend by pressing it, or with the left and right arrow keys. Then press Mark decision, or Mark mass. Mark every bend a decision, and the page is not kept. Press Erase this bend, and it does not succeed. The path stays on the bend it already took. The page can be kept only when at least one bend is marked mass. Marks may be changed. No score. No countdown.

    余像 / Afterimage

    账页分开记决定、质量、卡片。没有总数。

    The ledger keeps decision, mass, and the card apart. There is no total.
