昨日闪光

Yesterday's Flash

三下还亮着，只有一件能走进去。换料条：动手之前，先写下这块地已经会做的三件普通事。要让其中一件死掉，就在动手之前把它的名字写上去；事后再补一个理由，只是给已经换完的事配一个说法。条子问的不是新旧，是换过以后你还认不认得自己的日子。提前的影子：给一处该长植物的边写一周，只改邻居的一件事，让正午的影子提前两小时到场。一周结束，纸上要留一处说得清的伤——哪里薄了，哪里偏了，哪里没能装成没事。要紧的是有人能指着早到的邻居说，这一处没能若无其事。吐出来的那一口：判断训练只练一件事，快的这次接住了什么，慢的会在哪里把它吐出来，再加一句事先写好的话，这一口不许叫省下来的。写不出被吐出来的那一口，这张卡还没开始。接得更长，不等于读过了。

Three glints are still lit. Only one can be entered. The Material-Swap Slip: before anything is lifted, write down the three ordinary things this ground already does. If one of them is going to die, write its name down before the work starts; a reason offered afterwards is only an explanation fitted to something already done. The slip does not ask whether the new is better. It asks whether, after the swap, you still recognize your own days. The Early Shade: give one edge that ought to hold a plant a week, and change exactly one thing about its neighbour, so the noon shade arrives two hours early. When the week ends, the page must carry one scar that can be named, where it thinned, where it tilted, where it failed to pretend nothing had happened. What matters is that someone can point at the neighbour that came early and say this one could not stay nonchalant. The Spat-Out Breath: judgement training only practises one thing, what the fast one caught this time, where the slow one would spit it out, and one sentence written down beforehand, this breath must not be called a saving. If the spat-out breath cannot be written, the card has not begun. Catching more is not the same as having read.

      Work note / 作品说明

      换料条

      这块地已经会做三件普通事：雨往哪边走，正午影子盖住谁，有人穿过时哪条缝还在。先按这三件，把它们写进条子；不写满三件，换不了。换新漆，墙上的檐沟被填掉，雨不再往一边去。换新料，柱脚被填高，正午的影子短下来，够不到凳上的甲。换新路，新路一直铺过东篱上的缝，缝被盖住，没有人再穿过一条缝。要让其中一件死掉，先选中它，按写明这一件要死，再换。先换后写，条子上记的是换完才补的说法，这张条子就收不下。没有分数，没有倒计时。故意不发声。

      This ground already does three ordinary things: which way the rain goes, who the noon shadow covers, and which gap remains when someone walks through. Press the three first to write them onto the slip; no swap is possible until all three are written. New coat fills the groove on the west wall. New fill piles the base of the post so the noon shadow shortens and no longer reaches 甲 on the bench. New path is laid straight over the gap in the east fence. If one of them is going to die, select it and press Declare this one before the swap. Swap first and declare later, and this slip cannot be kept. No score. No countdown. Deliberate silence.
