# 昨日闪光 / Yesterday's Flash

公开名字用「昨日闪光」。文字层不是三件作品。不贴源链接，不贴邮件原文。

## 中文

三下还亮着，只有一件能走进去。

坏在哪一段：一页已经被压短。平均数还读作还好。承重的行里，有一行已经接不上。填白短了，不算坏。平均数不是一段。只有指出那条接不上的承重，才算说出坏在哪一段。用平均数收下，这页作废。再砍掉另一条还在的承重，也作废。除了你正指着的那一处断口，承重的行必须还在。

重渲一次：再画一遍。第二遍必须和第一遍不同，而且你要能说出不同在哪。说不出，就把第一遍放回去。两遍一样，不许叫重渲。

不像你的地方：即便整页都是你自己的字，仍会有一处不像你。那一处要单独留下来。它标出的是你没写下来的判断。把它改到像你，这页就没了。

## English

Three glints are still lit. Only one can be entered.

Which Span Broke: a page has already been shortened. The average still reads as fine. Among the load-bearing lines, one no longer continues. A shortened fill line is not a break. The average is not a span. Only pointing at the load-bearing line that no longer continues names where it broke. Keeping the page by the average voids it. Cutting another load-bearing line that still stands voids it too. Apart from the break you are naming, the load-bearing lines must still stand.

Draw It Again: draw it a second time. The second pass must differ from the first, and you must be able to name the difference. If you cannot name it, put the first pass back. Two passes that match may not be called a redraw.

Where It Is Not You: even when the whole page is in your own hand, one place will still not be you. That place must be kept alone. It marks a judgment you never wrote down. Changing it until it looks like you removes the page.
