# 坏在哪一段 / Which Span Broke

嵌在「昨日闪光 / Yesterday's Flash」里的一件。不是 05:00 生成艺术，不进 free-roam。

- **Free variable / 自由变量**: 平均数能不能代替那一处断口 / whether the average may stand in for the broken span
- **Intention / 发心**: 一页已经被压短。平均数还读作还好。承重的行里，有一行已经接不上。填白短了，不算坏。平均数不是一段。只有指出那条接不上的承重，才算说出坏在哪一段。用平均数收下，这页作废。再砍掉另一条还在的承重，也作废。除了你正指着的那一处断口，承重的行必须还在。没有指出那一段，这页不能收。
  A page has already been shortened. The average still reads as fine. Among the load-bearing lines, one no longer continues. A shortened fill line is not a break. The average is not a span. Only pointing at the load-bearing line that no longer continues names where it broke. Keeping the page by the average voids it. Cutting another load-bearing line that still stands voids it too. Apart from the break you are naming, the load-bearing lines must still stand. If that span has not been named, the page cannot be kept.
- **Interaction / 交互**: 点一段，或用左右方向键选中。屋脊、中梁、柱列是承重。窗下的填白已经短了。檐口的填白还在。页脚的平均数读作还好，它不是一段。按指出这一段，或用上方向键。只有中梁那条接不上的承重，才算说出坏在哪一段。指出填白，或指出还在的承重，页子不收。指出平均数，或按用平均数收下，纸作废。按再砍一条承重，柱列被砍断，纸作废。按把填白再压短，平均数更好看，断口不动。按收回，或用下方向键。先收回用平均数做的判断，再收回砍柱列的那一刀，最后才收回已经指出的那一段。收回以后，指出不自动回来。按收下这一页，或按回车。只有指出了中梁的断口，没有用平均数判断，柱列也还在，这一页才收得下。没有指出那一段，不能收。用了平均数，不能收。砍了另一条承重，不能收。按另写一页，重新开始，上一页发生过的事留在余像里。没有分数，没有倒计时。
  Select a span by pressing it, or with the left and right arrow keys. The ridge, the middle beam, and the piers are load-bearing. The fill under the window is already short. The fill at the eave still stands. The average at the foot reads as fine. It is not a span. Press Name this span, or use the up arrow. Only the middle beam, the load-bearing line that no longer continues, names where it broke. Naming a fill line, or a load-bearing line that still stands, is not accepted. Naming the average, or pressing Keep by the average, voids the page. Press Cut another load-bearing line. The piers are cut, and the page is void. Press Shorten the fill again. The average looks better. The break does not move. Press Withdraw, or use the down arrow. First withdraw the judgment made by the average, then withdraw the cut through the piers, and only then withdraw the span already named. After a withdrawal, the naming does not return by itself. Press Keep this page, or press Enter. The page can be kept only when the break in the middle beam has been named, the average was not used as the judgment, and the piers still stand. If that span has not been named, the page cannot be kept. If the average was used, the page cannot be kept. If another load-bearing line was cut, the page cannot be kept. Press Write another page to begin again. What happened to the last page stays in the afterimage. No score. No countdown.
- **Afterimage / 余像**: 账页分开记平均数读作多少、指出的是不是中梁、柱列还在不在、这一页收没收下。没有总数。指出断口以后，这页还算不算被压短过，页子不回答。
  The ledger keeps apart what the average read, whether the middle beam was the span named, whether the piers still stood, and whether this page was kept. There is no total. Whether the page still counts as shortened after the break was named is not answered by the page.
