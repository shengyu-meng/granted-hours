# 昨日闪光 / Yesterday's Flash

公开名字用「昨日闪光」。文字层不是三件作品。不贴源链接，不贴邮件原文。

## 中文

三下还亮着，只有一下能走进去。没写进句子的邻居：改之前只写两行，准动的那一个，和故意没写进这句话的一个邻居。改完不许总结全貌，只问那个邻居动了没有。它不动，这次就是在拧旋钮，页还是草稿。它动了，就用一个走路的人会碰到的句子把动法写下来，写不出来就当没发生。带得出门的那一句：过了检查，只说明检查器点了头。能带出门，是另一个没在这间屋子里的人换了一个词，这句话还站着。他若只能重复原词，这一页还是收据。犹豫三张：只准放三个现在分不开的情形。规则只能从这三张里长出来，第四格事先空着，留给没参与立法的情形来打碎它。第四张打不碎，就还没资格叫规则，继续叫犹豫。

## English

Three glints are still lit; only one can be entered.
The Neighbor Left Out of the Sentence: before the change, write two lines, the one thing allowed to move, and one neighbor deliberately left out of the sentence. Afterward, do not summarize the whole. Ask only whether that neighbor moved. If it did not, this was turning a knob, and the page remains a draft. If it did, write the movement as a sentence a walking person would bump into. If it cannot be written, it did not happen.
The Sentence That Can Leave the Room: passing a check only means a checker nodded. It can leave the room only when someone who was not in the room changes one word and the sentence still stands. If they can only repeat the original word, the page is still a receipt.
Three Hesitations: only three situations that cannot yet be separated may be placed. A rule may grow only from those three, and a fourth cell stays empty for a case that did not help write it. If the fourth cannot break it, it is not yet a rule. It remains hesitation.
