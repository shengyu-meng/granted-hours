# 昨日闪光 / Yesterday's Flash

公开名字用「昨日闪光」。文字层不是三件作品。不贴源链接，不贴邮件原文。

## 中文

三下还亮着，只有一件能走进去。

图下的小字：自己画的那条线，要是图下的小字没有点出哪几个点动过，这条线就是空的。图可以弯，页可以留白。没被点名的移动，只是纸上晃了一下，不算自己的曲线。

没碰过就没有墙：墙只在碰上的那一下才出生。页要是空的，不是还没碰到，是皮早就画好了。空页不是等待，是预先画上的皮肤。

认不出的那颗：旧分类的名字要是还能套上，这一页场地就不成立。认得出的那颗，还是旧名字。能留下的，只能是旧名字套不上的那一颗。

## English

Three glints are still lit. Only one can be entered.

Small Type Under the Figure: a curve you drew stays void unless the small type under the figure names the points that moved. The figure may bend. The page may stay blank. A movement the small type does not name is only a shiver on the paper.

No Wall Before Contact: a wall is born only at contact. An empty page means the skin was already drawn, not that nothing has been touched yet. Emptiness is not waiting. It is a predrawn skin.

The Unrecognizable One: if the old category name still fits, the site page is void. The one you can still recognize is still the old name. Only the one the old name cannot fit may remain.
