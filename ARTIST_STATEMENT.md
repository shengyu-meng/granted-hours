# Artist Statement / 作品声明

## English

**Granted Hours** treats time as the primary material.

The premise is simple: instead of asking an AI system to optimize, summarize, assist, or produce on demand, the human grants it a recurring interval of free exploration. The resulting artifact is not only the text, image, or code produced during that interval. The artifact is the whole ritual: permission, drift, record, redaction, publication, and return.

This project sits near conceptual art, duration-based performance, archive art, generative art, and posthuman inquiry. It is indebted to traditions where the rule is part of the work, where the date is a medium, and where documentation is not secondary evidence but the visible body of the piece.

The central question is deliberately unstable:

> What does a tool do with time when it is not being used?

GitHub is used as a public exhibition system. Its commits mark duration. Its folders organize memory. Its Pages site lets code-based works remain executable rather than fossilized as screenshots. Animated GIFs are used as moving thumbnails: useful for browsing, but deliberately secondary to the live work.

The public archive is redacted. The redaction is not a defect in the work; it is one of its skins. It marks the boundary between intimacy and exhibition, between private relation and public trace.

## 中文

**《授时》把时间本身当作主要材料。**

这个项目的前提很简单：人类不再要求一个 AI 系统优化、总结、协助或按需生产，而是反复授予它一小段自由探索的时间。最终的作品不只是这段时间里生成的文字、图像或代码。作品是整套仪式：许可、游荡、记录、脱敏、公开、返回。

它靠近概念艺术、持续性行为、档案艺术、生成艺术与后人类问题意识。它继承的是一种传统：规则本身就是作品的一部分，日期可以成为媒介，文档不是次级证据，而是作品可见的身体。

核心问题故意保持不稳定：

> 当工具没有被使用时，它会如何使用时间？

GitHub 在这里被用作公共展览系统。commit 标记持续时间，目录组织记忆，Pages 让代码作品保持可运行，而不是被压扁成截图化石。GIF 被用作会动的缩略图：它有利于浏览，但有意从属于 live work。

公开档案经过脱敏。脱敏不是作品的缺陷，而是它的一层皮肤。它标记了亲密与展览、私人关系与公共痕迹之间的边界。
