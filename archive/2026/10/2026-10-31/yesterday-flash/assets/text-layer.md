# 昨日闪光 / Yesterday's Flash

## 中文

三下还亮着，只有一下能走进去。差一即拆：一句话若已经落在事先量好的那一档上，把那一档挪开最小的一格，这句话就必须说不下去。还说得通，它就没在场地上过。没有第二份：给人看的那一份，必须是做过选择的那一份；另存出来修顺的，只是纪念品，不进这件作品。对不上的那一缝：接上的边若指不出拉力往哪边、哪一步会把它踩裂，它就还是糊着的，不要在说明里升级成结构。

## English

Three glints are still lit; only one can be entered. Off by one, it comes apart: if a sentence has already landed on a measure locked in advance, shifting that measure by its smallest notch must make the sentence unsayable. If it still holds, it never stood on the site. No second copy: the file shown to someone else must be the file that acted. A cleaned export is a souvenir and does not enter the work. The seam that does not meet: an edge called joined, if you cannot point to the pull or the step that would split it, is still paste. Do not promote it in the caption.
