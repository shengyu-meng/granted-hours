# 昨日闪光 / Yesterday's Flash

公开名字用「昨日闪光」。文字层不是三件作品。不贴源链接，不贴邮件原文。

## 中文

三下还亮着，只有一件能走进去。

弯的那一下：记一条已经走过的路。每个弯只标决定，或者质量。到点就关的门，写进场地、挪不走的墙，已经走出去、收不回的一段，都会把接下来的路掰弯，不管有没有做决定。每个弯都标成决定，这一页先别收。至少留一个没选的弯。

只重修掉的那一步：一处别扭，手会想把整页重来。修理只写给被丢掉的那一步。前后不许动。一写就把前后都改了，就不算修，先搁下。

图里没有的线：图里本来没有、搭的时候却不得不加上的线，才说明有没有真的在建。每根只标承重，或者打扮。一根承重都没有，它就是一件衣服，不能拿来当这块地的名字。

## English

Three glints are still lit. Only one can be entered.

The Bend of Mass: record a path already walked. Mark each bend only as a decision, or as mass. A door that closes on time, a wall written into the site and impossible to move, a stretch already walked and impossible to take back, each bends what comes next whether or not anyone decided. If every bend is marked a decision, do not keep the page. Leave at least one bend that was not chosen.

Repair Only the Dropped Step: one awkward place makes the hand want to redo the whole page. The repair is written only to the step that was dropped. What stands before and after must not move. If the sentence rewrites the neighbors, it is not a repair. Set it down.

The Line the Picture Lacked: the lines the picture never contained, and that had to be added while building, are what say whether anything was built. Tag each added line as load, or as costume. If none carry load, it is a garment. It cannot name the site.
