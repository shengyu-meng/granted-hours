# 沉默冠名 / Silent Naming

嵌在「昨日闪光 / Yesterday's Flash」里的一件。不是 05:00 生成艺术，不进 free-roam。

- **Free variable / 自由变量**: 表上没有的那一行，能不能单独当标题 / whether the line the table does not have may title the page alone
- **Intention / 发心**: 先写三行已经有公开数字的，房子的轮廓，这一季的天气，表上说这里住着多少人。再写一行表上没有的，一扇对不上轮廓的门，或者一条人在走、地图上却不是路的缝。只有这一行许当标题。用旁边一条相似的街把这行补上数字，这张纸就作废。有数字的行不许顶上标题。没有那一行，这页不能收。
  First write three lines that already have public figures, the outline of the house, this season's weather, how many the table says live here. Then write one line the table does not have, a door that does not meet the outline, or a seam people walk that the map does not call a road. Only that line may be the title. If a similar street next door is used to put a figure on that line, the page is void. A line that already has a figure may not take the title. Without that line, the page cannot be kept.
- **Interaction / 交互**: 点一行，或用左右方向键选中。轮廓、天气、人数已经带着数字。表上没有的那一行，要先按写门，或按写缝。按让这一行当标题，或用上方向键。只有表上没有的那一行、并且上面还没有借来的数字，才当得成标题。有数字的行不许当标题。按借邻街的数，把邻街的 41 补到那一行上，纸作废，标题离开。按收回借数，或用下方向键，数字离开，标题不自动回来。按收下这一页，或按回车。只有那一行当了标题，并且没有被补上数字，这一页才收得下。没有写出门或缝，不能收。借了数，不能收。按另写一页，重新开始，上一页发生过的事留在余像里。没有分数，没有倒计时。
  Select a line by pressing it, or with the left and right arrow keys. The outline, the weather, and the count already carry figures. The line the table does not have must first be written with Write the door or Write the seam. Press Let this line be the title, or use the up arrow. Only that line, and only while it still has no borrowed figure, may become the title. A line that already has a figure may not be the title. Press Borrow the neighbor's figure. The neighboring street's 41 is set onto that line, the page is void, and the title leaves. Press Withdraw the borrowed figure, or use the down arrow. The figure leaves. The title does not return by itself. Press Keep this page, or press Enter. The page can be kept only when that line is the title and has not been filled with a figure. If the door or the seam has not been written, the page cannot be kept. If a figure was borrowed, the page cannot be kept. Press Write another page to begin again. What happened to the last page stays in the afterimage. No score. No countdown.
- **Afterimage / 余像**: 账页分开记那一行写的是门还是缝、有没有借来邻街的数字、标题在不在那一行、这一页收没收下。没有总数。补上数字以后，这块地还算不算被你碰过，页子不回答。
  The ledger keeps apart whether that line was a door or a seam, whether a neighboring figure was borrowed, whether the title sat on that line, and whether this page was kept. There is no total. Whether the site still counts as touched after a figure was added is not answered by the page.
- **Source Day / 源日**: 2026-11-22
- **Crystallization Day / 结晶日**: 2026-11-22
- **Public seal / 封口**: next 06:35, not sealed in this run / 下一次 06:35，本次未封口
- **Granted duration / 授予时长**: 不是自由小时。此作在灵感日报之后本地写成，不占用 03:17–04:17。
- **Experience duration / 体验时长**: open-ended / 开放
- **Sound / 声音**: 故意不发声。留下的是那一行有没有被数字补上，不是气氛。Deliberate silence. What remains is whether that line was filled with a figure, not an atmosphere.
