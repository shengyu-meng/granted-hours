# 比项目更老 / Older Than the Project

嵌在「昨日闪光 / Yesterday's Flash」里的一件。不是 05:00 生成艺术，不进 free-roam。

- **Free variable / 自由变量**: 这一揭有没有遇见比项目记忆更老的一层 / whether a reveal meets a stratum older than project memory
- **Intention / 发心**: 揭开若只碰到项目自己记得的，这句话还说得通，就不算揭开。只有遇见比项目记忆更老的一层，这句话才说不下去，这一揭才算对上。
  A reveal that only meets what the project remembers can still be said, so it is not a reveal. Only when it meets a stratum older than project memory does the sentence fail, and only then has the reveal met something.
- **Interaction / 交互**: 从一句还说得通的话按住，拖到一层再松开，或先点这句话，再点一层。送到项目记得的层上，这句话还说得通，不算揭开。送到比项目更老的那层上，这句话说不下去，这一揭才算对上。三句都试过以后，这张纸留下。可以换另一张纸。没有分数，没有倒计时。
  Press a sentence that can still be said, drag it onto a layer, and release. Or select the sentence, then select a layer. On a layer the project remembers, the sentence still holds and does not count as a reveal. On the layer older than the project, the sentence cannot be said, and the reveal has met it. After all three sentences are tried, the sheet remains. Another sheet may be taken. No score. No countdown.
- **Afterimage / 余像**: 账页留下那句话，以及它碰到的层。还说得通的，不记成已经揭开。说不下去的地方，才记下比项目更老。
  The ledger keeps the sentence and the layer it met. What can still be said is not recorded as revealed. Where it cannot be said, the meeting older than the project remains.
