# 一起转的平面 / Co-rotated Planes

嵌在「昨日闪光 / Yesterday's Flash」里的一件。不是 05:00 生成艺术，不进 free-roam。

- **Free variable / 自由变量**: 一层少转十度以后，山还装不装得住 / whether, once one layer lags by ten degrees, the mountain can still pretend to stand
- **Intention / 发心**: 从脚底到树冠切开，每层只留那一高度真正切到的东西。换方向只能让所有层转同一个角度。唯一允许动手的地方，是让其中一层少转十度。少转的那一层露馅。露馅以后，纸必须承认，你以为站得住的山，是一组被要求一起转的平面。没有一层少转，这页不能收。
  Cut from the foot to the crown. Each layer may keep only what that height actually cuts. A change of direction may turn every layer only by the same angle. The only allowed hand is to let one layer lag by ten degrees. That layer gives the trick away. Afterward the page must admit that the mountain you thought could stand is a set of planes required to turn together. If no layer lags, the page cannot be kept.
- **Interaction / 交互**: 点一层，或用左右方向键选中。按全体左转或全体右转，六层转同一个角度，少转的那一层仍比同转少十度。按少转十度，或用上方向键，只许一层少转，再按一层，页子不收。按收回少转，或用下方向键，这一层回到同转。若山已经自报，少转一收回，自报也离开纸面。按山自报，或按回车，只在你正指着少转的那一层、并且已经露馅时，山才写下自己是一组被要求一起转的平面。还没露馅，不许抢先自报。按收下这一页。只有一层少转了十度，并且山已经自报，这一页才收得下。没有少转，山还装着站得住，不能收。露馅了却没自报，这页作废。按另写一页，重新开始，上一页发生过的事留在余像里。没有分数，没有倒计时。
  Select a layer by pressing it, or with the left and right arrow keys. Press Turn all left or Turn all right. Six layers turn by the same angle, and a lagging layer still remains ten degrees short of that shared turn. Press Lag by ten degrees, or use the up arrow. Only one layer may lag. A second layer is not accepted. Press Withdraw the lag, or use the down arrow. That layer returns to the shared turn. If the mountain has already confessed, withdrawing the lag takes the confession off the page. Press Let the mountain confess, or press Enter, only while you are pointing at the lagged layer and the trick has already shown. Before the trick shows, the mountain may not confess early. Press Keep this page. The page can be kept only when one layer lags by ten degrees and the mountain has confessed. If nothing lags, the mountain is still pretending to stand, and the page cannot be kept. If the trick has shown and the mountain has not confessed, the page is void. Press Write another page to begin again. What happened to the last page stays in the afterimage. No score. No countdown.
- **Afterimage / 余像**: 账页分开记同转的方向、少转的那一层、山有没有自报、这一页收没收下。没有总数。露馅以后，山还算不算站得住，页子不回答。
  The ledger keeps the shared direction, the layer that lagged, whether the mountain confessed, and whether this page was kept, apart. There is no total. Whether the mountain still counts as standing after the trick shows is not answered by the page.
