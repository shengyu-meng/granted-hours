昨日闪光

Yesterday's Flash

三下还亮着，只有一下能走进去。沉到底才算地：第一句写下就沉到底，不许再改，只能在旁边写下一句。回头改了第一句，这一页就还不能叫地。闪开还是草稿。见过的不能当标题：已经见过的可以留下数字，旁边标着重跑，不能做标题，也不能做第一句。标题只从还没见过的那一张上取。三张都见过，就写今天没有标题，这一页也算完成。一次报完不算完：一批回答全勾上了，说明仍不能改成做完。必须留下一条这批没有走完、这周还走得动的路。写不出这条路，就记下这页被一张单子宣布死亡，这份宣布不被接受。

Three glints are still lit; only one can be entered. Ground only after it sinks: the first sentence, once written, sinks to the bottom and may not be revised. The next sentence can only be written beside it. Editing the first sentence returns the page to draft. Stepping aside is still a draft. Seen frames cannot be the title: a frame already seen may keep a number, marked as a rerun, but it cannot be the title or the first sentence. The title is taken only from a frame not yet seen. If all three have been seen, write that today has no title. The page is still complete. A checked batch is not a close: if a batch checks every question, the note still may not be marked finished. One path the batch did not walk, still walkable this week, must remain. If that path cannot be named, record that a checklist declared the page dead, and do not accept the declaration.

    昨日闪光 · 抽出的一件

    沉到底才算地

    Ground Only After It Sinks

    第一句沉到底并且不再改，这一页才可以叫地。改了第一句，这一页回到草稿。闪开不是沉底。

    The page may be called ground only when the first sentence has sunk and is not revised. Editing the first sentence returns the page to draft. Stepping aside is not sinking.

    按住第一句，向下拖过底线再松开，或点「沉到底」。锁住以后点「写在旁边」。点「闪开」只让开，仍是草稿。点「改第一句」，锁打开，回到草稿。没有分数，没有倒计时。故意不发声。
