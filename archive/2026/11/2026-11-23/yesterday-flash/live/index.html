昨日闪光

Yesterday's Flash

三下还亮着，只有一件能走进去。坏在哪一段：一页已经被压短。平均数还读作还好。承重的行里，有一行已经接不上。填白短了，不算坏。平均数不是一段。只有指出那条接不上的承重，才算说出坏在哪一段。用平均数收下，这页作废。再砍掉另一条还在的承重，也作废。除了你正指着的那一处断口，承重的行必须还在。重渲一次：再画一遍。第二遍必须和第一遍不同，而且你要能说出不同在哪。说不出，就把第一遍放回去。两遍一样，不许叫重渲。不像你的地方：即便整页都是你自己的字，仍会有一处不像你。那一处要单独留下来。它标出的是你没写下来的判断。把它改到像你，这页就没了。

Three glints are still lit. Only one can be entered. Which Span Broke: a page has already been shortened. The average still reads as fine. Among the load-bearing lines, one no longer continues. A shortened fill line is not a break. The average is not a span. Only pointing at the load-bearing line that no longer continues names where it broke. Keeping the page by the average voids it. Cutting another load-bearing line that still stands voids it too. Apart from the break you are naming, the load-bearing lines must still stand. Draw It Again: draw it a second time. The second pass must differ from the first, and you must be able to name the difference. If you cannot name it, put the first pass back. Two passes that match may not be called a redraw. Where It Is Not You: even when the whole page is in your own hand, one place will still not be you. That place must be kept alone. It marks a judgment you never wrote down. Changing it until it looks like you removes the page.

      Work note / 作品说明

      坏在哪一段

      一页已经被压短。平均数还读作还好。点一段，或用左右方向键选中。按指出这一段，或用上方向键。只有中梁那条接不上的承重，才算说出坏在哪一段。指出填白，或指出还在的承重，页子不收。指出平均数，或按用平均数收下，纸作废。按再砍一条承重，柱列被砍断，纸作废。按把填白再压短，平均数更好看，断口不动。按收回，或用下方向键。按收下这一页，或按回车。没有指出那一段，不能收。用了平均数，不能收。砍了另一条承重，不能收。没有分数，没有倒计时。故意不发声。

      A page has already been shortened. The average still reads as fine. Select a span by pressing it, or with the left and right arrow keys. Press Name this span, or use the up arrow. Only the middle beam, the load-bearing line that no longer continues, names where it broke. Naming a fill line, or a load-bearing line that still stands, is not accepted. Naming the average, or pressing Keep by the average, voids the page. Press Cut another load-bearing line, and the piers are cut. Press Shorten the fill again. The average looks better. The break does not move. Press Withdraw, or use the down arrow. Press Keep this page, or press Enter. If that span has not been named, the page cannot be kept. If the average was used, the page cannot be kept. If another load-bearing line was cut, the page cannot be kept. No score. No countdown. Deliberate silence.
