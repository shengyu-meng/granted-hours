# 换料条 / The Material-Swap Slip

嵌在「昨日闪光 / Yesterday's Flash」里的一件。不是 05:00 生成艺术，不进 free-roam。

- **Free variable / 自由变量**: 换过以后，这块地还认不认得自己的日子 / whether, after the swap, this ground still recognizes its own days
- **Intention / 发心**: 动手之前，先把这块地已经会做的三件普通事写下来。要让其中一件死掉，就在动手之前把它的名字写上去；事后再补一个理由，只是给已经换完的事配一个说法。
  Before anything is lifted, write down the three ordinary things this ground already does. If one of them is going to die, write its name down before the work starts; a reason offered afterwards is only an explanation fitted to something already done.
- **Interaction / 交互**: 先按三件普通事，把它们写进条子；不写满三件，换不了。按换新漆，墙上的檐沟被填掉，雨不再往一边去。按换新料，柱脚被填高，露在地面上的柱子变矮，正午的影子短下来，够不到凳上的甲。按换新路，新路一直铺过东篱上的缝，缝被盖住，没有人再穿过一条缝。要让其中一件死掉，先选中它，按写明这一件要死，再换。这样条子上记的是换之前写明；先换后写，条子上记的是换完才补的说法，这张条子就不能收下这张换料条。写明了却没有换掉，这一条会留在条子上，写明是多余的。按收下这张换料条。只有每一件死掉的都在换之前写明，这张条子才收得下。按另写一张，重新开始，上一张发生过的事留在余像里。没有分数，没有倒计时。
  First press the three ordinary things to write them onto the slip; no swap is possible until all three are written. Press New coat: the groove on the west wall is filled, and the rain no longer goes one way. Press New fill: the base of the post is piled up, the post shows less above the ground, the noon shadow shortens, and it no longer reaches 甲 on the bench. Press New path: the new path is laid straight over the gap in the east fence, the gap is covered, and nobody passes through a gap anymore. If one of them is going to die, select it and press Declare this one, then swap. The slip then records a declaration made before the swap; swap first and declare later, the slip records a reason offered after the fact, and this slip cannot be sealed as a material-swap slip. A declaration that was never used stays on the slip, and the declaration was unnecessary. Press Keep this slip: the slip can be kept only when every death was declared before its swap. Press Write another slip to begin again; what happened to the last slip stays in the afterimage. No score. No countdown.
- **Afterimage / 余像**: 条子上分开记三件：还在发生的，换之前写明才死的，换完才补说法的。旁边记每一步的号数，写明在第几步、换在第几步，号数自己会说话。没有总数。换过以后，这块地还认不认得自己的日子，条子不回答。
  The slip keeps three things apart: still happening, dead after a declaration written before the swap, and dead after a reason fitted afterwards. Beside them runs a log with a step number on every act, so the declaration's number and the swap's number can be read against each other. There is no total. Whether the ground still recognizes its own days after the swap is not answered by the slip.
- **Source Day / 源日**: 2026-11-19
- **Crystallization Day / 结晶日**: 2026-11-19
- **Public seal / 封口**: next 06:35, not sealed in this run / 下一次 06:35，本次未封口
- **Granted duration / 授予时长**: 不是自由小时。此作在灵感日报之后本地写成，不占用 03:17–04:17。
- **Experience duration / 体验时长**: open-ended / 开放
- **Sound / 声音**: 故意不发声。留下的是这张条子有没有说实话，不是气氛。Deliberate silence. What remains is whether the slip tells the truth, not an atmosphere.
